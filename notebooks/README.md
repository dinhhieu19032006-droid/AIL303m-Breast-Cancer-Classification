# Notebook dự án

Notebook hiện có:

- `01_kham_pha_va_tien_xu_ly.ipynb` - xác minh nguồn, kiểm tra chất lượng, EDA và chuẩn bị dữ liệu. Notebook không huấn luyện mô hình.
- `02_thiet_lap_du_lieu_thi_nghiem.ipynb` - tạo train/test split cố định dùng chung. Notebook không chuẩn hóa hay huấn luyện mô hình.
- `03_knn.ipynb` - baseline, tuning KNN, trực quan hóa parameter và đánh giá một lần trên tập test chung.

Kế hoạch sau khi nhóm hoàn tất xác minh dataset:

1. `04_svm.ipynb` - baseline và tuning SVM.
2. `05_decision_tree.ipynb` - baseline và tuning Decision Tree.
3. `06_tong_hop_ket_qua.ipynb` - bảng so sánh và phân tích cuối cùng.

Các notebook chỉ được tạo khi nhóm đã thống nhất các quy ước trong `docs/03_quy_uoc_du_lieu_va_danh_gia.md`.
