# Quản lý dữ liệu

## Dữ liệu hiện có

File CSV gốc của nhóm nằm tại `data/Craw_data/data.csv`.

Không chỉnh sửa, đổi tên hoặc ghi đè file này. Mọi bước làm sạch sau này phải đọc từ file gốc và tạo dữ liệu dẫn xuất ở một thư mục riêng.

## Cấu trúc dự kiến

| Vị trí | Mục đích |
| --- | --- |
| `Craw_data/` | Dữ liệu gốc tải về từ Kaggle |
| `processed/` | Dữ liệu dẫn xuất sau khi đã ghi rõ quy trình tiền xử lý |

Thư mục `processed/` hiện chưa có dữ liệu vì nhóm chưa bước vào giai đoạn tiền xử lý thực nghiệm.
