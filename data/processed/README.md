# Dữ liệu đã xử lý

Thư mục này chứa dữ liệu dẫn xuất có thể tái lập từ file gốc.

Sau khi chạy `notebooks/01_kham_pha_va_tien_xu_ly.ipynb`, thư mục sẽ có file `breast_cancer_clean.csv`.

File này được tạo trực tiếp từ notebook, giữ cột `diagnosis` ở dạng `B/M`, loại `id` và cột rỗng hoàn toàn của file export. File không được chuẩn hóa, không được chia train/test và không phải kết quả mô hình.

Không sao chép hoặc thay thế dữ liệu gốc trong `data/Craw_data/`.
